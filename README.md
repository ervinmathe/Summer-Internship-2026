# Lomoadmin Beta 2026

Code written during my first summer internship at **LOMO SOFT CONSULT**.

This is a demo project containing implementations of various solutions that can serve as a reference, and be customized to fit the company's admin app.

## Prerequisites

* **.NET 7.0 SDK** or later installed on your machine

## Dependencies

* **Microsoft.ClearScript.V8** `v7.5.1`
* **Microsoft.ClearScript.V8.Native.win-x64** `v7.5.1`
* **Microsoft.CodeAnalysis.CSharp.Scripting** `v5.6.0`
* **Microsoft.CSharp** `v4.7.0`
* **Scintilla.NET** `v5.3.2.9`
* **Scintilla5.NET** `v7.0.0`
* **ScintillaNET_FindReplaceDialog** `v1.5.5`
